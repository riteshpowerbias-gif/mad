# 04_CurrentLocation - Get User Location

An Android app demonstrating how to obtain and display the device's current GPS/Network latitude and longitude coordinates using Google Play Services `FusedLocationProviderClient`.

## Testing Location in Android Emulator

1. Open and run the project on an Android Emulator.
2. Open the emulator's **Extended Controls** panel by clicking the **`...`** (three dots) button on the emulator toolbar.
3. Select the **Location** tab.
4. Enter test coordinates (e.g., Latitude `37.422`, Longitude `-122.084`) and click **Set Location** (or **Send**).
5. Grant location permissions when prompted in the app.
6. The app will receive and display the latitude and longitude on screen.
